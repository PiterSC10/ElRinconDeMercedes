# El Rincón de Mercedes 🌸

Editor de postales para Mercedes. Aplicación web estática publicada exclusivamente en GitHub Pages. Las fotografías y postales se guardan localmente en el navegador; no se suben a GitHub.

## Publicación

GitHub → Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

> GitHub Pages es público. El almacenamiento local no proporciona sincronización entre dispositivos ni control de acceso a la web.
