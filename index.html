📖 Manuales del Rincón de Mercedes

Guías sencillas para crear, personalizar, guardar y compartir postales.

Manual 1 · Crear tu primera postal
  1. Selecciona el formato: cuadrado, vertical u horizontal.
  2. Pulsa «Empezar postal con este formato».
  3. Escoge una celebración y una plantilla premium.
  4. Escribe el título, nombre, mensaje y firma.
  5. Comprueba la postal completa a la derecha antes de descargarla.
Manual 2 · Elegir el formato correcto

Cuadrado: práctico para WhatsApp e Instagram. Vertical: felicitaciones largas o para imprimir. Horizontal: postales panorámicas o con foto amplia. El formato se bloquea al empezar; para cambiarlo, pulsa «Cambiar formato y reiniciar». La aplicación solicitará confirmación.

Manual 3 · Añadir y mover stickers

Abre «Elementos decorativos», selecciona una categoría y pulsa un sticker para añadirlo. Arrástralo sobre la postal para colocarlo. Usa los botones para ampliar, reducir, traer delante o eliminar el elemento seleccionado. Puedes combinar varios.

Manual 4 · Personalizar el texto y las fotografías

Los textos del título, nombre, mensaje y firma pueden editarse libremente. «Añadir texto libre» agrega otra frase como elemento movible. Puedes subir una fotografía familiar, que se ajusta al espacio reservado para ella sin tapar el encabezado. Las fotos no se envían a servidores.

Manual 5 · Descargar e imprimir

PNG: formato sin pérdida para conservar e imprimir. JPG: imagen de alta calidad para compartir. «Imprimir / PDF» permite guardar como PDF desde el diálogo de impresión. La vista previa se reduce al espacio disponible, pero la exportación se renderiza a mayor resolución.

Manual 6 · Guardar y recuperar recuerdos

Usa «Guardar» para conservar la postal editable en este navegador. En «Mis postales» podrás abrirla y seguir trabajando. Exporta copias de seguridad JSON de forma periódica. Si borras los datos del navegador, podrías perderlas.

Privacidad: GitHub Pages es público y esta aplicación no cuenta con contraseña real. Las fotos y proyectos se guardan localmente en el navegador; no hay sincronización automática.
