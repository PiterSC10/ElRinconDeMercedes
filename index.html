Importante: GitHub Pages es público y esta web no tiene autenticación. Las fotos se procesan en tu navegador y se guardan localmente. No se suben a GitHub. Si borras los datos del navegador, puedes perder los proyectos; exporta una copia JSON para conservarlos.

Las copias se pueden importar en otro navegador, pero no existe sincronización automática.
